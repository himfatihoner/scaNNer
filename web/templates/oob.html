Modules OOB Collaborator

📡 OOB Collaborator LOCAL ONLY

Built-in HTTP listener for SSRF/XXE/blind-XSS/SSTI proof callbacks. Local-listener-based — works only when the TARGET can reach scaNNer's host.

Read before use — this module needs network reachability

scaNNer opens a local HTTP listener. For the target server to call back, it must be able to reach this listener's IP:port. That means:

  • ✓ Works when scaNNer runs on the same LAN as the target (internal pentest, CTF, lab)
  • ✓ Works when scaNNer is on a VPS / cloud host with a public IP and the listen port is firewall-open
  • ✓ Works when you've port-forwarded the listener through a VPN tunnel (Tailscale, WireGuard, ngrok HTTP)
  • ✗ DOES NOT work from your laptop on residential NAT — outbound-only, target can't reach you
  • ✗ NO DNS authority — XXE / blind-SSRF via subdomain queries won't surface here (no DNS server)
  • ✗ NO HTTPS — modern targets may refuse to fetch plain-HTTP callbacks (mixed-content / strict TLS policies)

For real public-target engagements, use: Interactsh (oast.fun) — public DNS+HTTP+SMTP collaborator, polled via REST API; or Burp Collaborator — included in Burp Suite Pro. These services solve the reachability + DNS + HTTPS problems you DON'T get from a local listener.
